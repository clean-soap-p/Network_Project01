# 네트워크 보안 프로젝트

가상 핀테크 기업 MW금융(카드 혜택 비교·추천 플랫폼)의 본사 및 지사 네트워크를 설계하고, 금융 보안 정책을 적용하여 점검한 기록입니다.
코리아IT아카데미 대구 정보보안 과정 네트워크 보안 과목에서 진행했습니다.

## 1. 프로젝트 개요

- **기업명**: MW금융 (핀테크 / 카드 혜택 추천 앱 및 웹 포털 운영)
- **규모**: 총 20명 (대구 본사 15명 / 서울 지사 5명)
- **핵심 목표**: 
  - 부서 간 VLAN 망 분리 및 엄격한 DB 접근 제어(ACL)
  - 대구 본사 ↔ 서울 지사 간 암호화 통신 (Site-to-Site IPsec VPN)
  - 대고객 금융 서비스 보호를 위한 3-Tier DMZ 보안 아키텍처 구축
  - 침해 공격(DDoS, 스푸핑 등) 모의 훈련 및 방화벽 대응
